Agregação: perguntas por projeto
MongoDB ($group)
db.comentario.aggregate([
  { $group: {
      _id: "$projeto",
      perguntas: { $sum: 1 },
      curtidas:  { $sum: "$curtidas" },
      respostas: { $sum: { $size: { $ifNull: ["$respostas", []] } } }
  } }
])
SQL equivalente (se as perguntas estivessem em tabelas)
SELECT c.projeto_id,
       COUNT(*)        AS perguntas,
       SUM(c.curtidas) AS curtidas,
       SUM((SELECT COUNT(*) FROM resposta r
            WHERE r.comentario_id = c.id)) AS respostas
FROM comentario c
GROUP BY c.projeto_id;

Por que MongoDB aqui? Comentários têm estrutura flexível e volume variável por projeto. O MongoDB permite inserir documentos sem schema rígido — ideal para dados que evoluem com o tempo (ex: adicionar curtidas, respostas aninhadas) sem migrations. A pergunta e suas respostas são lidas e gravadas como uma unidade — exatamente o padrão de acesso da página do projeto.
